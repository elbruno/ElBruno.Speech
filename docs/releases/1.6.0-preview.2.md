# ElBruno.Speech 1.6.0-preview.2

Release preparation only. This version has not been published. Preview.2 adds
an experimental, opt-in local Whisper large-v3 CPU STT provider. The opt-in
Parakeet provider was already included in `1.6.0-preview.1`. Existing
`ElBruno.Whisper`, Parakeet, and speech-pipeline defaults remain unchanged.

## Changes and local evidence

- Adds `ElBruno.Speech.Stt.Whisper`, backed by Whisper.net 1.9.1 / whisper.cpp
  CPU, for the pinned multilingual large-v3 GGML model. The provider and model
  are opt-in; weights are explicitly downloaded and are not packaged.
- Keeps `ElBruno.Speech.Stt.Parakeet` as the experimental local ONNX provider
  released in preview.1. No Parakeet model or default changes are included.
- Local-only evaluation used the immutable FLEURS bundle: ten English and ten
  Spanish clips. The Whisper provider report covered all 20 clips and its
  hypotheses/edit counts exactly matched the separate benchmark report. The
  recorded small-bundle comparison measured Whisper WER at 16/420 (3.81%)
  versus Parakeet INT8 at 19/420 (4.52%), while Whisper took 773.24 seconds
  versus 8.74 seconds for INT8 on the measured host. These are limited,
  machine-specific observations, not a general accuracy or performance claim.
- The local .NET 8 native cancellation/reuse smoke test passed. Recorded-audio
  fixture evaluation and model inference remain local-only, not GitHub Actions
  or publish-workflow checks.

FLEURS has no reviewed word timestamps. Whisper's native segment times are
model output, not reviewed timing or forced alignment. No podcast accuracy
claim is made; independent podcast and timing requirements remain open in
issue #101.

## Model, license, and native limits

The library/packages use MIT licensing. The pinned Whisper GGML model repository
declares MIT; required Whisper.net / whisper.cpp notices are included with the
provider package. The released Parakeet model bundle is CC BY 4.0 and its
third-party notices are included. These model/runtime terms are separate from
the library license; retain the applicable notices.

Whisper large-v3 is a 3,095,033,483-byte unquantized GGML model and is not
included in NuGet. It requires several GiB of memory and CPU inference is
computationally expensive. The package uses Whisper.net 1.9.1 and supports .NET
8 and .NET 10 on platforms supported by its native runtime. On Windows, the
upstream runtime requires Windows 11 / Server 2022 or later, the Visual C++ 2022
redistributable, and AVX, AVX2, FMA, and F16C for the standard x64 CPU runtime.
Unsupported native environments fail explicitly; no CUDA installation or
automatic model/runtime fallback is provided.

Parakeet accepts mono 16 kHz PCM16, raw or WAV-wrapped. Its measured/validated
provider support is Windows x64 CPU on .NET 8 and .NET 10; Linux, macOS, ARM,
GPU, trimming, and Native AOT are not validated. Native token-start metadata
is available, but word/segment intervals and detected-language identifiers are
not. Independent chunks can cut words. Parakeet weights are not bundled.
