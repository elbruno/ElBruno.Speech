# ElBruno.Speech 1.6.0

Stable release candidate for the opt-in Ollama Phonon text-to-speech provider,
bringing the preview implementation onto main alongside the dependency refresh.

## Changes

- Adds `ElBruno.Speech.Tts.Ollama`, an opt-in MEAI `ITextToSpeechClient`.
  `services.AddOllamaSpeech()` defaults to local Ollama, the `phonon` model,
  the model's default voice, and WAV output. Server base URLs resolve to the
  speech route automatically; full endpoints and explicit overrides still work.
- Supports complete WAV/PCM responses, incremental HTTP streaming, cancellation,
  explicit unsupported-option validation, and HTTP error reporting. Includes a
  runnable C# sample and synthetic provider/sample coverage for .NET 8 and 10.
- Includes the opt-in Parakeet TDT v3 and Whisper large-v3 STT providers introduced
  during the 1.6 previews. Existing Whisper and speech-pipeline defaults do not
  change. Their documented model, timing, licensing, and evaluation limits remain.
- Updates Microsoft.Extensions.DependencyInjection, DependencyInjection.Abstractions,
  Hosting, Logging.Abstractions, and Options to 10.0.14, and OpenTelemetry.Api and
  OpenTelemetry.Extensions.Hosting to 1.20.1.
- Updates build/test tooling: SourceLink 10.0.403, bUnit 2.13.3,
  Microsoft.AspNetCore.Mvc.Testing 8.0.33, and CodeQL action 4.39.1.

Two users tested the HelloPhonon sample using `1.6.0-preview.5`:

| [Apple M2 Max report](https://github.com/elbruno/ElBruno.Speech/issues/106#issuecomment-6403213175) | Mac Studio M2 Max, .NET 10, Ollama 0.40.11 | Generated and played `hello.wav` with `afplay`; user reported clear English speech. |

These independent community reports address the previously pending live WAV
generation/listening check on supported hardware. They are not exhaustive tests
of every voice, streaming mode, quality, performance, or platform. No new real
Phonon inference was run on the release operator's Windows machine.

## Requirements and limitations

- Ollama speech currently requires a supported Apple Silicon Mac with MLX.
  Windows/Linux server support remains pending upstream with no promised date.
  A Windows/Linux .NET client may call a compatible remote server.
- Phonon is oriented toward English, with a 4,096-character request limit.
  A Spanish sentence was reported playable but with a strong English accent;
  this release does not claim multilingual TTS quality.
- Native audio is 24 kHz mono PCM16, either WAV-wrapped or raw PCM. Pipeline
  integration still requires matching the configured output format and explicit
  conversion/resampling where needed. Streaming chunks are transport fragments,
  not standalone WAV files or guaranteed sample-aligned PCM frames.
- Stable NuGet numbering does not remove the upstream MEAI speech APIs'
  experimental annotation. Model weights, voices, MLX, and fallback runtimes
  are not bundled. Model and native-runtime licenses remain separate.
- The Parakeet/Whisper evaluation limitations remain unchanged, including no
  newly reviewed podcast accuracy, word/segment timing, or language-ID claims.

## Complete package set and release gate

All packages use version `1.6.0`: Abstractions, Audio, Vad.Silero, Stt.Parakeet,
Stt.Whisper, Tts.Ollama, Pipeline, AspNetCore, NAudio, OpenTelemetry, Cli, and
BlazorComponents, each prefixed with `ElBruno.Speech`.

Publication requires a successful exact-commit dry run of
`.github/workflows/publish.yml` and independent review of the version, these
release notes, package metadata/readmes/licenses, target frameworks/dependencies,
and all twelve NuGet packages and twelve matching symbol packages, including
BlazorComponents. Build, tests, pack, and package-presence checks must pass.
Publish only through that workflow after approval. This document describes
the candidate; publication evidence is recorded on the GitHub release.
