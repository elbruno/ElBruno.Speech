# ElBruno.Speech 1.6.0-preview.3

Release candidate for the experimental, opt-in Ollama Phonon text-to-speech
provider. Publication status is tracked by the GitHub release and NuGet feed,
not implied by the presence of these notes.

## Changes

- New `ElBruno.Speech.Tts.Ollama` implements
  `Microsoft.Extensions.AI.ITextToSpeechClient`, registered with
  `services.AddOllamaSpeech()`.
- Configurable complete endpoint (default
  `http://localhost:11434/v1/audio/speech`), model (`phonon`), optional voice,
  and WAV/PCM format. Per-request model, voice, and format overrides are supported.
- Full audio responses and incremental streaming use MEAI `DataContent`, plus
  compatibility `RawRepresentation` byte arrays. Audio is mono PCM16 at 24 kHz;
  raw PCM is little-endian.
- Cancellation, HTTP error details, response-stream disposal, input-length checks,
  and explicit rejection of unsupported speed/language/pitch/volume/additional
  options. No undocumented fields are sent to Ollama.
- Runnable [OllamaSpeechDemo](../../src/samples/OllamaSpeechDemo/README.md):
  DI registration, complete WAV, incremental PCM, finalized playable WAV
  headers, audio format/non-silence checks, local timing output, and optional
  post-generation playback.
- Root README, provider/sample guides, architecture, pipeline, audio-format,
  implementation-status, and release documentation describe the new provider.
  Publish-workflow checks now require all twelve packages.
- The publish workflow pins the previously verified .NET SDKs 8.0.426 and
  10.0.402. The initial release dry run failed before compilation because
  floating SDK channels resolved to unavailable downloads; no packages were
  published by that failed attempt.

## Platform and verification limits

Ollama speech currently runs on Apple Silicon Macs with MLX. The speech
capability docs specify Ollama 0.40.9+, while the announcement recommends
0.40.11+. Windows and Linux speech-server support is pending upstream with no
promised date. A Windows .NET client can call a supported remote Ollama server.

On the tested Windows host, Ollama 0.40.11 reported:

```text
ollama pull phonon
Error: this model requires MLX support, but the MLX runtime is not available
```

The C# sample's live request returned HTTP 404 (model not installed), with a
clear error and nonzero exit code. **No real Phonon audio was generated or
listened to.** Twenty-one focused synthetic provider/sample test cases cover
each of .NET 8 and .NET 10. These cover request fields, supported formats,
option/length validation, errors, cancellation, first-chunk delivery before EOF,
early-disposal cleanup, WAV header finalization, byte preservation, and
invalid/silent audio rejection and bounded error-body reading. They do not establish speech quality, voice
accuracy, model throughput, or live-server compatibility.

This remains Ollama-only. No standalone Phonon runtime, MLX library, voice,
model weights, cloud service, or automatic fallback is bundled or installed.
Run `ollama pull phonon` separately on the supported inference host. Phonon is
currently English-oriented by default; model/voice licensing is separate from
the MIT .NET client.

Pipeline orchestration and default providers are unchanged. The existing
pipeline assumes raw PCM matching `SpeechPipelineOptions.TargetFormat`.
Applications must not feed WAV containers or unconverted 24 kHz samples to
its default 16 kHz output path. See [audio formats](../audio-formats.md).

## Release review and publication

Before publication, the reviewer must confirm version, release notes,
metadata/readmes/licenses, dependencies/frameworks, and the complete package
set, including `ElBruno.Speech.BlazorComponents`. Require a successful
`.github/workflows/publish.yml` dry run on the exact reviewed commit with
`version=1.6.0-preview.3` and `dry_run=true`; inspect all twelve NuGet and twelve
symbol artifacts and verify build, tests, pack, and package-presence checks.
Publish only after that review through the same workflow. Recorded-audio
fixtures and model inference are not added to CI.

[platform announcement](https://ollama.com/blog/speech-models), issue #106.
