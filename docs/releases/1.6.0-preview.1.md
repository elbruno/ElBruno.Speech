# ElBruno.Speech 1.6.0-preview.1

Published as `1.6.0-preview.1`. This preview added an experimental opt-in
Parakeet provider. It did not replace Whisper or establish verified podcast
accuracy or alignment.

## Changes

- New `ElBruno.Speech.Stt.Parakeet` package implementing
  `Microsoft.Extensions.AI.ISpeechToTextClient` with local CPU ONNX Runtime.
- Explicit downloads from a pinned, SHA-256-verified
  [Hugging Face model bundle](https://huggingface.co/elbruno/parakeet-tdt-0.6b-v3-onnx/tree/2a5f66ac53dfc1c817e75609d9903d75b4ec5895).
  No downloads during construction/inference and no cloud inference dependency.
- Native token-start metadata with explicit chunk-padding flags, cancellation,
  bounded chunks, DI registration, and the `ParakeetTranscribe` JSON sample.
- Documentation of supported input, licensing, measured local behavior, and
  independent evaluation gaps. See [Parakeet documentation](../parakeet.md).

## Limits

Input must be mono 16 kHz PCM16, raw or WAV wrapped. Other formats require
conversion. Native word/segment intervals, token ends, detected-language fields,
translation, and incremental acoustic streaming are not available. Independent
chunks can cut words. Only Windows x64 CPU has been exercised for this provider.
The model is CC BY 4.0, distinct from the library's MIT license.

Both supplied No Tiene Nombre podcast recordings were processed locally, but
Whisper baseline artifacts and independently reviewed text/alignment references
are still needed. Issue #101 remains open; model hypotheses are not ground truth.
