# ElBruno.Speech 1.6.0-preview.5

Release candidate for zero-configuration Ollama speech examples and default-value
regression coverage.

## Changes

- Primary code examples now use `services.AddOllamaSpeech()` without options.
  The existing defaults are `http://localhost:11434/`, model `phonon`, the
  model's default voice, and WAV output. The speech route resolves automatically.
  No change to the established default request behavior is needed.
- Omitted options, explicit `null`, and empty `OllamaSpeechOptions` all use
  these defaults. Partial options override only the supplied settings.
- The console demo now uses library option defaults for endpoint/model instead
  of maintaining duplicated runtime values. Endpoint and voice flags still work.
- Update provider/sample guides, root README, architecture, implementation
  status, blog draft, runnable blog code, and DI API documentation.
- Forty-nine focused synthetic cases cover the provider/sample on each of
  .NET 8 and .NET 10, including no-options DI registration and actual complete
  and streaming request defaults. Existing normalization, overrides, cancellation,
  error handling, and audio format behavior remain unchanged.

## Platform and audio limits

Local Ollama speech currently requires a supported Apple Silicon Mac with MLX.
Windows/Linux inference-server support is pending upstream with no promised date;
a Windows client may use a supported remote server. No real Phonon audio has
been generated or listened to in this work. Synthetic tests do not establish
pronunciation or audio quality. No weights, voices, recordings, MLX runtime,
or non-Ollama fallback are bundled. Pipeline defaults remain unchanged.

## Release gate

Require independent review of version, exact commit, release notes, package
metadata/readmes/licenses, frameworks/dependencies, and all twelve NuGet and
twelve symbol artifacts, including BlazorComponents, following a successful
exact-commit dry run of `.github/workflows/publish.yml`. Build, tests, pack,
and package-presence checks must pass. Publish only through that workflow
after review.

The complete package set is Abstractions, Audio, Vad.Silero, Stt.Parakeet,
Stt.Whisper, Tts.Ollama, Pipeline, AspNetCore, NAudio, OpenTelemetry, Cli, and
BlazorComponents, all prefixed with `ElBruno.Speech`, at `1.6.0-preview.5`.
