# ElBruno.Speech 1.6.2 (planned)

This planned stable release adds .NET 11 target assets while retaining existing
.NET 8 and .NET 10 assets. BlazorComponents also targets .NET 10 and .NET 11,
in addition to its previous .NET 8 target.

The CLI retains its .NET 8 tool asset and major-version roll-forward instead of
adding a separate .NET 11 asset. Packing both tool TFMs duplicates their native
dependencies, producing a 325,537,878-byte package (310.5 MiB), above
NuGet.org's 250 MB limit. The current-size .NET 8 tool asset was installed and
run successfully against isolated .NET 8-only and .NET 11-only runtime sets.

All twelve packages are set to version `1.6.2`:

- `ElBruno.Speech.Abstractions`
- `ElBruno.Speech.Audio`
- `ElBruno.Speech.Vad.Silero`
- `ElBruno.Speech.Stt.Parakeet`
- `ElBruno.Speech.Stt.Whisper`
- `ElBruno.Speech.Tts.Ollama`
- `ElBruno.Speech.Pipeline`
- `ElBruno.Speech.AspNetCore`
- `ElBruno.Speech.NAudio`
- `ElBruno.Speech.OpenTelemetry`
- `ElBruno.Speech.Cli`
- `ElBruno.Speech.BlazorComponents`

No public API, runtime package dependency, or speech pipeline default changes
are intended. The Blazor test dependency is updated for .NET 11 compatibility.
ONNX/Parakeet and Whisper inference continue to use their existing
CPU/native runtime constraints. Ollama Phonon still requires an Ollama host
with MLX support; the Windows/Linux server limitation is unchanged.

Publication remains pending release review. Verify the complete package set,
including `ElBruno.Speech.BlazorComponents`, and the workflow's build, test,
pack, and package-presence checks before publishing through
`.github/workflows/publish.yml`.
