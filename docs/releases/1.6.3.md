# ElBruno.Speech 1.6.3

This maintenance release follows the CodeQL GitHub Actions update. It retains
the .NET 8, .NET 10, and .NET 11 assets and existing runtime dependencies from
1.6.2. There are no public API, runtime behavior, or speech pipeline default
changes.

All twelve packages are released together at version `1.6.3`:

- `ElBruno.Speech.Abstractions`
- `ElBruno.Speech.Audio`
- `ElBruno.Speech.Vad.Silero`
- `ElBruno.Speech.Stt.Parakeet`
- `ElBruno.Speech.Stt.Whisper`
- `ElBruno.Speech.Tts.Ollama`
- `ElBruno.Speech.Pipeline`
- `ElBruno.Speech.AspNetCore`
- `ElBruno.Speech.NAudio`
- `ElBruno.Speech.OpenTelemetry`
- `ElBruno.Speech.Cli`
- `ElBruno.Speech.BlazorComponents`

Runtime package dependencies are unchanged. The CLI remains a `.NET 8` tool
with major-version roll-forward and runs on .NET 11 without requiring a .NET 8
runtime installation. Existing native inference and Ollama platform
requirements are unchanged.

The trusted `.github/workflows/publish.yml` workflow builds, tests, packs, and
verifies all twelve packages and symbol packages before publishing.
