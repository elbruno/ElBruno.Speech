# ElBruno.Speech 1.6.4

This dependency-maintenance candidate retains the .NET 8, .NET 10, and .NET 11
package assets and all twelve package IDs. It does not change public speech
contracts, pipeline defaults, or supported hardware providers.

Dependency updates:

- Microsoft.ML.OnnxRuntime: 1.31.1 to 1.32.0.
- NAudio: 2.3.0 to 2.4.0, with the WinMM dependency referenced explicitly.
- Microsoft.Extensions 10.x packages: 10.0.14 to 10.0.15; Microsoft.Extensions.Http
  moves from 10.0.9 to 10.0.15. Existing dependency-injection overrides move
  from 10.0.12 to 10.0.15.
- OpenTelemetry core: 1.17.0 to 1.20.1, aligned with the existing API and hosting
  packages.
- Microsoft.SourceLink.GitHub: 10.0.403 to 10.0.404.
- Microsoft.NET.Test.Sdk: 18.11.0 to 18.12.0; coverlet.collector: 10.1.0 to
  10.1.1.
- Microsoft.AspNetCore.Mvc.Testing and Microsoft.AspNetCore.Components.Web:
  8.0.34.

Microsoft.Extensions.AI remains at 10.11.0 to preserve the supported target
framework and dependency graph. NAudio 2.x is retained to preserve .NET 8
support and the existing WinMM audio behavior. The NAudio 2.4 buffer setup
preserves the configured playback duration; Windows-specific APIs are annotated
and guarded where the CLI and sample invoke them.

All twelve packages are intended to ship together at version `1.6.4`, including
`ElBruno.Speech.BlazorComponents`. The trusted
`.github/workflows/publish.yml` workflow must build, test, pack, and verify all
twelve package and symbol-package artifacts, followed by independent release
review, before publication.
