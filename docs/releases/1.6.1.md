# ElBruno.Speech 1.6.1

Patch release with dependency updates. No public API or speech-pipeline default
changes.

## Changes

- Updates `Microsoft.Extensions.Hosting.Abstractions` from 10.0.12 to 10.0.14,
  aligning it with the other Microsoft.Extensions 10.0.14 dependencies.
- Updates `Microsoft.ML.OnnxRuntime` from 1.31.0 to 1.31.1, a patch release.

## Compatibility

- Targets .NET 8 and .NET 10, with `ElBruno.Speech.BlazorComponents` targeting
  .NET 8.
- No model weights or voices are bundled. Existing provider platform
  requirements, licensing terms, and evaluation limitations are unchanged.

## Complete package set and release gate

All packages use version `1.6.1`: Abstractions, Audio, Vad.Silero,
Stt.Parakeet, Stt.Whisper, Tts.Ollama, Pipeline, AspNetCore, NAudio,
OpenTelemetry, Cli, and BlazorComponents, each prefixed with `ElBruno.Speech`.
Each package must include its NuGet package and matching symbol package.

Publication requires a successful exact-commit dry run of
`.github/workflows/publish.yml` and review of the version, release notes,
package metadata, readmes/licenses, target frameworks/dependencies, and all
twelve package pairs, including BlazorComponents. Build, tests, pack, and
package-presence checks must pass. Publish only through that workflow after
review.
