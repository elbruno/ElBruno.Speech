# ElBruno.Speech 1.6.0-preview.4

Release candidate for simpler Ollama speech endpoint configuration.

## Changes

- Configure `Endpoint = new Uri("http://localhost:11434/")`, now the default.
  The library resolves the route to `/v1/audio/speech`.
- Paths ending in `/v1` or `/v1/audio`, with or without trailing slashes, are
  completed automatically. Full speech routes are not duplicated; their
  trailing slash is normalized. Both complete and streaming requests use the
  same options-snapshot logic, including DI registration.
- Preserve HTTPS, ports, proxy prefixes before `/v1`, and query strings.
  Other custom endpoint paths remain unchanged for backward compatibility.
  A proxy base should include `/v1`, such as `https://host/proxy/v1/`.
- Caller-owned options are not mutated. Relative and non-HTTP(S) URLs remain
  invalid. No speculative URL rewriting, network probing, or fallback requests.
- Update the provider guide, console sample/help, root README, architecture,
  implementation status, and code-focused blog draft and runnable example.
- Forty-three focused synthetic provider/sample cases pass on each of
  .NET 8 and .NET 10, including endpoint normalization in both response modes,
  default configuration, snapshot isolation, query preservation, and invalid URLs.

The prior `1.6.0-preview.3` package is unchanged and requires the full speech URL.
Other providers use local inference or fixed model download URLs, not configurable
HTTP inference bases; WebSocket and health routes are distinct contracts and are
not rewritten.

## Platform and audio limits

This remains an opt-in Ollama-only preview. A supported Apple Silicon Mac with
MLX is required for Ollama speech today. Windows/Linux server support is pending
upstream, with no promised date. A Windows .NET client may call a supported remote
server. No real Phonon speech has been generated or listened to in this work;
synthetic tests do not verify intelligibility or audio quality.

Audio remains mono 24 kHz PCM16, with WAV or raw little-endian PCM output. Pipeline
defaults and conversion behavior are unchanged. No model weights, recorded audio,
voice assets, MLX libraries, or alternative runtime are bundled.

## Release gate

Before publication, an independent review must confirm the exact version and
commit, release notes, metadata/readmes/licenses, frameworks/dependencies, and
all twelve NuGet packages with twelve matching symbol packages, including
`ElBruno.Speech.BlazorComponents`. Require a successful exact-commit dry run
of `.github/workflows/publish.yml`, inspecting its build, tests, pack, presence
checks, and actual artifacts. Publish through that workflow only after approval.

The complete package set is Abstractions, Audio, Vad.Silero, Stt.Parakeet,
Stt.Whisper, Tts.Ollama, Pipeline, AspNetCore, NAudio, OpenTelemetry, Cli, and
BlazorComponents, all prefixed with `ElBruno.Speech`, at `1.6.0-preview.4`.
