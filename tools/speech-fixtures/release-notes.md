Reusable CC BY 4.0 speech test fixtures: ten complete English and ten complete
Spanish FLEURS test recordings, with independent source transcript references.

The ZIP contains PCM16 WAV files, a provider-neutral JSON manifest, checksums,
attribution, and license notices. Verify the ZIP using its `.sha256` sidecar, then
verify individual files against `manifest.json`. Audio/reference licensing remains
CC BY 4.0, separate from the library's MIT license.

This small regression set has no reviewed word timestamps and is not evidence of
podcast accuracy or absence of model pretraining overlap. It contains no model
weights and does not publish or change NuGet packages.

See `docs/speech-fixtures.md` at this release's commit for provenance, scoring, and
cross-repository reuse instructions.
